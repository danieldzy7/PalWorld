# Hero Image Setup Instructions

To use your cat house image as the hero background:

## Quick Steps:

1. **Save the image** you want to use as: `hero-cats.jpg`
2. **Place it in the `img` folder** in your PalWorld directory
3. **Refresh your browser** - the image will appear as the hero background!

## File Location:
```
PalWorld/
└── img/
    └── hero-cats.jpg  <-- Save your image here
```

## Alternative Names:
If you want to use a different filename, update line 92 in `styles.css`:
```css
background-image: url('img/YOUR-FILENAME.jpg');
```

---

The image you showed (cats in modern home with cat house) will look perfect as the hero background! 🐱🏠
