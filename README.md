# Pal World Cat Litter Website

A stunning, modern website showcasing Pal World's premium natural cat litter collection with a clean, image-focused design inspired by top e-commerce brands like Tuft & Paw.

## Features

- **Full-Width Hero Sections**: Immersive hero banners using your product photography
- **4 Product Showcase**: Complete catalog featuring all cat litter products
- **Individual Product Pages**: Detailed pages for each product with specifications
- **Feature Detail Sections**: Alternating image/text layouts highlighting key benefits
- **Customer Testimonials**: Social proof with 5-star reviews
- **Newsletter Integration**: Email capture for customer engagement
- **Fully Responsive**: Flawless experience on all devices
- **Modern Design**: Clean black & white aesthetic with bold typography
- **Smooth Animations**: Subtle hover effects and transitions

## How to Use

**Option 1: Direct Open**
- Simply double-click `index.html` to open in your default browser

**Option 2: Local Server (Recommended)**
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Then visit http://localhost:8000
```

## Design Inspiration

Inspired by modern e-commerce leaders like [Tuft & Paw](https://www.tuftandpaw.com/):
- Bold, oversized typography (Inter font family)
- Minimalist black and white color scheme
- Full-width hero images with overlay text
- Generous white space
- Product cards with hover effects
- Clean grid layouts
- Subtle shadows and transitions

## Key Design Elements

- **Typography**: Inter font family (300-800 weights)
- **Color Scheme**: Black (#000), White (#FFF), Gray tones
- **Layout**: Maximum width 1400px with 40px padding
- **Images**: Full-width banners, grid product layouts
- **Buttons**: Uppercase text with letter spacing
- **Shadows**: Subtle layered shadows for depth

## Customization

To customize colors, update CSS variables in `styles.css`:

```css
:root {
    --black: #000000;
    --white: #FFFFFF;
    --gray-light: #F8F8F8;
    --gray-medium: #666666;
    --gray-dark: #333333;
}
```
